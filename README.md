# ChatFixs
A 26.1.2 Paper plugin that lets users set a prefix or suffix for their chat messages!
> [!NOTE]
> The *fix is NOT for the player's name, it is for their chat message content.

Commands:  
- `/chatfixs set [prefix|suffix] (*fix)` - sets the chat *fix
- `/chatfixs unset [prefix|suffix]` - removes chat *fix
> [!NOTE]
> These commands set/unset the *fix for the player running them.  
> *fixes for each player are stored in the plugin's `fixs.yml`.

There is no configuration, or permissions. This plugin was intended for my personal server. If you want to add configuration or permissions, make a PR!
