# ChatPrefix
A 26.1.2 Paper plugin that lets users set a prefix for their chat messages!
> [!NOTE]
> The prefix is NOT for the player's name, it is for their chat message content.

Commands:  
- `/chatprefix set <prefix>` - sets the chat prefix
- `/chatprefix unset` - removes chat prefix
> [!NOTE]
> These commands set/unset the prefix for the player running them.  
> Prefixes for each player are stored in the plugin's `config.yml`.

There is no configuration, or permissions. This plugin was intended for my personal server. (theres probably a better plugin than this anyways)
